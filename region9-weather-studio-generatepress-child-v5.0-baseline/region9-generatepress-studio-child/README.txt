Region 9 Weather Studio 4.0

GeneratePress child theme production release.

Included:
- Cumulative 3.x features
- Emergency Mode homepage
- Latest Weather Update enable/disable control
- Live NWS alert ticker and Alert Center
- Clickable current conditions with full city forecasts
- Observation age warnings
- Live system status panel
- Social profile hub and graphic sharing
- High contrast and reduced-motion support
- Lazy-loaded radar and media
- Admin health diagnostics
- JSON settings export/import
- Site builder/repair tool

Installation:
1. Install and activate GeneratePress.
2. Upload this ZIP under Appearance > Themes > Add New.
3. Activate Region 9 Weather Studio.
4. Run Region 9 Studio > Site Setup > Build or Repair Entire Site.
5. Configure Region 9 Studio > Live Controls.
6. Clear all WordPress, GoDaddy, CDN, and browser caches.
