# Region 9 Live Studio 17 Alpha 7 Forecast Production Engine

Alpha 7 adds a deterministic forecast production engine that creates public, structured product objects from the approved canonical publication state only. Generation does not call NOAA, SPC, WPC, NWS, LLMs, AI services, or any external API.

## Product IDs

`morning-brief`, `todays-forecast`, `seven-day-forecast`, `headlines`, `severe-weather-risk`, `threat-breakdown`, `storm-timing`, `travel`, `agriculture`, `fieldwork`, `spraying`, `harvest`, `livestock`, `outdoor`, `schools`, `construction`, `forecast-confidence`, `decision-support-brief`, `watching`.

## Schema

Each product contains: `product_id`, `title`, `product_version`, `publication_version`, `updated_at`, `effective_start`, `effective_end`, `risk`, `score`, `confidence`, `affected_counties`, `timing`, `summary`, `discussion`, `primary_drivers`, `secondary_drivers`, `source_times`, `approval_state`, `publication_state`, `history_id`, and `rollback_reference`. Products are pure data; theme HTML is not generated by the service.

## Timing behavior

UTC/Z timestamps are normalized to `America/Chicago` with daylight saving time awareness. Single times, ranges, overnight rollovers, and labels such as Morning, Late Morning, Afternoon, Late Afternoon, Evening, and Overnight are supported. Exact source timestamps remain in `source_times`.

## County aggregation

The county matrix is fixed to Kankakee, Iroquois, Ford, Livingston, DeWitt, Piatt, Champaign, Vermilion, and McLean. Each county keeps its own score, rating, confidence, drivers, timing, and summary. The Region 9 aggregate score follows the existing decision engine rule: the public Region 9 risk reflects the maximum affected county score so the highest impacted county is not hidden by averaging.

## REST endpoints

All endpoints are read-only under `/wp-json/region9-live-studio/v1/`: `/products`, `/product/{id}`, `/todays-forecast`, `/seven-day-forecast`, `/travel`, `/agriculture`, `/fieldwork`, `/spraying`, `/harvest`, `/livestock`, `/outdoor`, `/schools`, `/construction`, `/severe-weather-risk`, `/threat-breakdown`, `/storm-timing`, `/forecast-confidence`, `/headlines`, `/morning-brief`, `/decision-support-brief`, `/watching`, `/county-product-matrix`, and `/product-history`.

Public endpoints return approved, published data only. Pending changes, rule traces, audit logs, and override internals are excluded. Write routes remain administrator-only through the existing admin-post workflow.

## Theme integration

Use `r9ls_get_published_product($id)`, `r9ls_get_published_products()`, `r9ls_get_widget_payload($id)`, `[r9ls_product id="travel"]`, or `[r9ls_county_matrix]`. Helpers only read stored product data; no scheduler, external weather request, DOM scanning, MutationObserver, or automatic page rebuild is triggered during rendering. If the plugin is inactive, themes should wrap calls in `function_exists()`.

## Caching and history

Public product payloads are cached with product-key transients. Publication invalidates only changed product keys plus the aggregate product cache. Content hashes prevent unchanged products from being regenerated into new versions. Product history is immutable and stores version, publication version, generated/published timestamps, actor, approval reference, material-change reason, previous version, rollback reference, and content hash.

## Security behavior

Read endpoints expose public forecast products only. Administrative write actions require `manage_options`, nonces, sanitization, and escaped output. Public rendering never exposes audit logs, rule traces, or override internals.

## Known limitations

Alpha 7 is deterministic and intentionally conservative. Discussion text becomes shorter when approved source data is sparse. Seven-day detail is limited by the canonical state currently stored by Alpha 6 ingestion and decision output.

## Staging installation

Run `bash scripts/build-region9-live-studio-zip.sh`, upload the generated ZIP from `build/`, activate Region 9 Live Studio, run the validation suite, then approve and publish a canonical state before enabling public pages that display products.
