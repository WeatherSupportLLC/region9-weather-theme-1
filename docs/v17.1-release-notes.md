# Region 9 Live Studio 17.1.0 release notes

## Release summary

Region 9 Live Studio 17.1.0 completes the operational repair of the GeneratePress child theme and Live Studio plugin. The release preserves the existing theme folder, stylesheet slug, page URLs, menus, widget assignments, Customizer settings, and GP Premium compatibility.

## Public homepage

- Restores the live radar/map as the prominent homepage feature with configured URL behavior, lazy loading, status, fallback, and full-radar navigation.
- Restores the two-column operational layout and true right sidebar.
- Restores Alert Center, Weather Operations, Current Region 9 Risk, Forecast Confidence, emergency resources, and related-product navigation in the sidebar.
- Restores the Power Outage Tracker with configured provider links, safe unavailable/stale/informational states, branded fallback graphics, and full-page navigation.
- Preserves Decision Impact Dashboard, Current Conditions, headlines, today/seven-day forecasts, graphics, discussions, timestamps, responsive stacking, header, navigation, footer, and branding.

## Forecast Production

- Successful manual and scheduled validation now persist one private workspace row per enabled canonical product.
- Stable content hashes prevent timestamp-driven version churn; changed content increments a draft version while unchanged content remains reviewable at the existing version.
- Decision History records every successful validation and Publication History records immutable publish/rollback events.
- Product and batch approval, rejection, and publication enforce capabilities, nonces, canonical IDs, and rejection reasons.
- Explicit publication promotes only approved products. Rejected, pending, and malformed products remain private.
- Product-level rollback restores an immutable historical snapshot without rewriting history.
- Targeted cache invalidation leaves unrelated product caches intact.

## Alert Center and administration

- Alert Center uses canonical normalized state for alert counts, watches, warnings, advisories, counties, timeline, health, refresh status, and instructions without exposing raw payloads.
- One authoritative Region 9 Studio menu now provides dedicated operational dashboards for automation, production, products, approvals, decisions, publications, alerts, sources, scheduler, setup, system health, backup, live controls, partners, clients, rural operations/reports, and protection.
- Source telemetry tracks success/failure times, latency, retry status, cache age, and errors.
- Backup/restore uses a size-limited, schema-validated option allowlist.

## Upgrade and safety

- The idempotent 17.1.0 migration accepts clean, RC1, and partially migrated option structures.
- It preserves canonical publications, workspace, decision/publication/product histories, material changes, overrides, live controls, scheduler settings, source health, canonical alerts, and WordPress theme/menu/widget state.
- Automatic publication remains disabled by default.
- Public REST and theme helpers expose only approved and published canonical products.

## Known upstream limitations

- The requested v15/v15.1 reference ZIPs were unavailable in the execution filesystem; repository inventories and executable parity guards remain the available baseline.
- Production source availability, 24–48 hour scheduler soak evidence, authenticated browser screenshots, GP Premium behavior, object-cache behavior, and staging operator sign-off require the staging environment.
