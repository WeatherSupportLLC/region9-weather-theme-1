# Region 9 Live Studio 17.1.0 rollback procedure

## Exact rollback order

1. Re-enter maintenance mode, stop editorial publication activity, record the incident start time, and preserve logs/screenshots/current certification and health output.
2. Export the current Region 9 backup and take a fresh database snapshot before changing files; preserve failed-version artifacts for investigation.
3. Restore the **prior plugin ZIP first** to the existing `region9-live-studio` directory and activate/reactivate it as required.
4. Restore the **prior child-theme ZIP second** to the exact predeployment child-theme directory. Confirm the GeneratePress child remains active; do not create a new theme slug.
5. Restore the predeployment database only if file rollback cannot read the preserved option schemas safely, migration changed data incorrectly, or canonical publication/workspace/history state is damaged. Obtain owner approval before database restoration because it can remove post-backup editorial changes.
6. Restore uploads only if the incident affected media files.
7. Clear plugin transients and authorized WordPress/page/object/CDN caches; do not manually delete canonical publication/history evidence.
8. Verify one scheduler event, next run, no stale lock, automatic-publication setting, source health, Alert Center, workspace, Decision History, Publication History, latest publication, and public products.
9. Smoke-test homepage radar/sidebar/outage/forecasts, REST public boundaries, admin dashboards, approval/publication, and product-level rollback.
10. Exit maintenance mode only after operational owner approval.
11. Preserve database/file snapshots, server/PHP logs, audit exports, source-health records, failed artifacts/checksums, timestamps, and operator notes as incident evidence.

## Product-only rollback

When code and schema are healthy but one publication is incorrect, use Publication History to roll back only that product. Confirm a new immutable rollback event is created and unrelated products/caches remain unchanged; do not restore the entire database for a product-content issue.
